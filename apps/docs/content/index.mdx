# omnireact

A collection of independent, headless React packages. MIT licensed. Each package installs
on its own and only depends on `@omnireact/core` — never on a sibling feature package.

```bash
pnpm add @omnireact/dialog
```

## Packages

- [`@omnireact/dialog`](/dialog) — headless, imperative dialog API
  (`useDialogs()` → `open`/`close`/`alert`/`confirm`/`prompt`).

More packages (initializer, data, ...) are planned.
